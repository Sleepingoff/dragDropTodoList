## 파일 개요

index.js는 애플리케이션의 진입점 역할을 하며, 상태 관리 및 할 일(To-Do) 관리와 관련된 주요 이벤트를 처리합니다. 이 파일은 DOM 요소를 초기화하고, 사용자 입력 이벤트를 처리하며, 상태 및 할 일 데이터를 화면에 반영합니다.

## 주요 구성 요소

1. 의존성
   store: 애플리케이션의 데이터 저장소를 관리하는 모듈.
   StatusManager: 상태 관리와 관련된 로직을 처리하는 클래스.
2. DOM 요소 초기화
   section: 상태와 할 일을 표시하는 메인 섹션.
   statusForm: 새로운 상태를 추가하기 위한 폼.
   statusInput: 상태 입력 필드.
   todoForm: 새로운 할 일을 추가하기 위한 폼.
   todoInput: 할 일 입력 필드.
   deleteBtn: 할 일을 삭제하기 위한 드롭 영역.
   기능별 문서화
3. 기본 상태 초기화
   역할: 애플리케이션 실행 시 기본 상태(archive, progress, done)를 화면에 표시하고, 각 상태에 대한 리스트를 생성.

4. 상태 추가

   폼 제출 이벤트를 감지.
   입력값 검증 후 새로운 상태를 추가.
   상태를 화면에 표시하고 입력 필드를 초기화.

5. 할 일 추가

   폼 제출 이벤트를 감지.
   입력값 검증 후 새로운 할 일을 생성.
   저장소를 업데이트하고, 할 일 목록을 갱신.
   각 할 일 항목에 드래그 이벤트를 추가.

6. 할 일 삭제

   작동 방식:
   삭제 버튼에 드래그 앤 드롭 이벤트를 추가.
   드롭된 할 일을 삭제하고 화면 및 저장소를 갱신.
